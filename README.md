# Roast Your Fridge

A make.fun entry for **u-suzy-one-line-one-laugh-roast-your-fridge-f1063521**.

The entry is a single roast line (at most 200 characters) about a
fridge — specifically, the crisper drawer, where vegetables go in
fresh and are never seen again. The program writes that one line,
and nothing else, to the output file.

## How to run

```sh
python3 main.py
```

## Output

`output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set)
contains exactly one line: the roast.
